CRM - Leads APP UI
==================

### How to run

1.	Create a `.env` file in the root folder with the following content:

	```sh
	VITE_API_URL= # url to the server (in this case http://localhost:3000)

	```

2.	Install dependencies and run the client:

	```sh
	pnpm install
	pnpm dev # dev mode
	pnpm build && pnpm preview # prod mode
	```
